# Attributions

Aeolus does not invent license terms. Summaries below point to primary sources; consult those sources for authoritative text.

## Open-Meteo

Weather API data via [Open-Meteo](https://open-meteo.com/). Attribution guidance: https://open-meteo.com/en/license

Underlying model providers accessed through Open-Meteo include:

- **ECMWF** — European Centre for Medium-Range Weather Forecasts
- **DWD** — Deutscher Wetterdienst (ICON)
- **NOAA** — National Oceanic and Atmospheric Administration (GFS)

## RainViewer

Radar imagery via the [RainViewer](https://www.rainviewer.com/) public Weather Maps API. See RainViewer terms/API documentation for current attribution requirements.

## MapLibre

[MapLibre Native Android](https://maplibre.org/) — BSD-style open-source map rendering.

## OpenFreeMap / OpenStreetMap

Basemap tiles: [OpenFreeMap](https://openfreemap.org/).

Map data © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors (ODbL).

## Weather condition labels

WMO weather-code text labels are shown in v1 (no separate icon asset pack bundled). A permissively licensed icon set such as [Meteocons](https://github.com/basmilius/weather-icons) may be added in a later release with its license notice.

## Libraries

Third-party Android libraries (AndroidX, Compose, Retrofit, OkHttp, kotlinx.serialization, Coil, MapLibre, etc.) retain their respective open-source licenses as distributed through Maven artifacts.
